# SmartSpend
*(Java Project)*

---

SmartSpend is a simple, user-friendly desktop application built with Java, designed to help students manage their personal finances effectively. Users can register, log in, track income and expenses, and receive monthly summaries via email.

## Key Features

* **User Authentication**: Secure user registration and login system.
* **Transaction Management**: Easily add and view; income and expense records.
* **Dynamic Balance**: See your current balance updated in real-time.
* **Data Persistence**: All user and transaction data is saved locally in `.csv` files.
* **Email Reporting**: Generate and receive a complete financial summary directly to your registered email.

## Tech Stack

* **Language**: Java (JDK 21)
* **User Interface**: Java Swing
* **Build Tool**: Apache Maven
* **Dependencies**:
    * OpenCSV (for file handling)
    * Jakarta Mail (for sending emails)

## Download & Run (For End-Users)

This is the easiest way to use the application if you already have Java installed.

1.  **Download the Executable JAR:**
    * Download `SmartSpend-1.0-SNAPSHOT.jar` from the "Assets" section below.
2.  **Run the Application:**
    * Open your terminal or command prompt.
    * Navigate to the directory where you downloaded the JAR file.
    * Execute the command:
        ```bash
        java -jar SmartSpend-1.0-SNAPSHOT.jar
        ```
    * *(Requires Java Development Kit (JDK) or Java Runtime Environment (JRE) version 21 or higher.)*

### **Configure Email Reports (Mandatory for Email Functionality)**

To enable the "Email Report" feature, you need to set up your own Gmail account for sending.

1.  **Enable 2-Step Verification** on your Google Account:
    * Visit [myaccount.google.com/security](https://myaccount.google.com/security).
2.  **Generate an "App Password"**:
    * Go to [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords).
    * Follow the instructions to create a new App Password (e.g., name it "SmartSpend App"). Google will provide a **16-character password**. Copy this password.
3.  **Create `config.properties`**:
    * In the **same directory** where you placed the `SmartSpend-1.0-SNAPSHOT.jar` file, create a new text file named `config.properties`.
4.  **Add Your Credentials**:
    * Open `config.properties` and add your Gmail address and the 16-character App Password:
        ```properties
        EMAIL_USER=your.email@gmail.com
        EMAIL_PASS=your16characterapppassword
        ```
        *(**Important**: Replace `your.email@gmail.com` with your actual Gmail address and `your16characterapppassword` with the unique 16-character App Password generated by Google.)*

## Building from Source (For Developers)

If you wish to build the application from its source code, follow these steps.

### **Prerequisites**

* **Java Development Kit (JDK)**: Version 21 or later.
* **Apache Maven**: Version 3.6 or later.
* **Git**: For cloning the repository.

### **Steps**

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Arpitha-P-Ajay/SmartSpend.git
    ```
2.  **Open in IDE**: Open the project in a Java IDE (VS Code, IntelliJ IDEA, Eclipse). The IDE will handle dependency downloads via Maven.
3.  **Configure Email (for local development/testing)**:
    * Navigate to `src/main/resources/`.
    * Create `config.properties` and add your `EMAIL_USER` and `EMAIL_PASS` (as described in the "Configure Email Reports" section above). This file is ignored by Git.
4.  **Build the Project**:
    * Open a terminal in the project's root directory and run:
        ```bash
        mvn clean install
        ```
5.  **Run from IDE**: Execute the `main` method in `src/main/java/com/smartspend/App.java` to start the application.
